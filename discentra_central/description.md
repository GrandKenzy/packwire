# Packwire

Packwire es un gestor nativo de paquetes para Windows, escrito en Rust. Ofrece una CLI y una interfaz gráfica para descubrir, instalar y administrar herramientas, lenguajes de programación, runtimes y sistemas operativos desde un catálogo de manifests.

La versión 1.0.0 es estable y se distribuye como instalador y paquete portable para Windows.
