# Ficha técnica

| Campo | Detalle |
|---|---|
| Nombre | Packwire |
| Versión estable | `1.0.0` |
| Plataforma | Windows 10/11 |
| Arquitectura | x64 |
| Tipo | Gestor de aplicaciones y herramientas |
| Interfaz | GUI nativa y CLI |
| Tecnología | Rust |
| Requisito GUI | Microsoft Edge WebView2 Runtime |
| Conexión | Internet para consultar y descargar paquetes |
| Distribución | Instalador y versión portable |

## Archivos de descarga

| Archivo | Uso |
|---|---|
| `Packwire-Setup.exe` | Instalación recomendada en Windows |
| `packwire-windows-x64.zip` | Versión portable sin instalador |

## Incluye

- Catálogo de paquetes, herramientas, lenguajes y runtimes.
- Instalación y consulta de versiones.
- Interfaz gráfica (`packwirew.exe`).
- CLI (`packwire.exe`).
- Detección y administración de aplicaciones instaladas.
