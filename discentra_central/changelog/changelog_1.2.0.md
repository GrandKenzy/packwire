# Packwire 1.2.0

- Catálogo remoto de manifests sincronizado desde GitHub al iniciar Packwire.
- Caché local validada para continuar usando el catálogo sin conexión.
- Los manifests dejan de incluirse dentro del instalador y del paquete portable.
- Los manifests nuevos, modificados o eliminados en GitHub se reflejan en la caché local.
