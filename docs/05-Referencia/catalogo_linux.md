# Catálogo Linux

Packwire incluye un filtro `Linux` en el catálogo. Las entradas son enlaces a
las páginas oficiales de descarga: Packwire no descarga ni ejecuta imágenes ISO
automáticamente, porque la selección de arquitectura, edición y medio de
instalación depende del equipo destino.

Las recomendaciones son orientativas: antiX y MX Linux priorizan equipos con
recursos limitados; Debian, Ubuntu Server, Rocky Linux, AlmaLinux y openSUSE
Leap están orientados a servidores; Fedora, Arch, Tumbleweed, NixOS y Pop!_OS
favorecen herramientas recientes o control técnico; Linux Mint, Ubuntu Desktop,
Zorin y elementary OS son opciones generales de escritorio.

Antes de crear el USB, conviene revisar en la página oficial la arquitectura,
la edición y las sumas o firmas de la ISO. Debian, Fedora, Arch y antiX publican
instrucciones de verificación en sus páginas de descarga.
