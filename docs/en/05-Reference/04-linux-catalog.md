# Linux Catalog Guide

Packwire includes a catalog of official Linux distributions tailored to developer workflows and system administration.

---

## 1. Curated Profiles

### Development & Programming
- **Fedora Workstation:** Modern toolchains, cutting-edge kernel, robust developer defaults.
- **Arch Linux:** Minimal rolling release for advanced users requiring immediate access to latest packages.
- **NixOS:** Declarative, reproducible development environments with configuration rollbacks.
- **Pop!_OS:** Refined desktop with native NVIDIA graphics integration.

### Server & Infrastructure
- **Ubuntu Server LTS:** Standard enterprise and cloud server platform with long-term maintenance.
- **Debian Stable:** Rock-solid stability for mission-critical infrastructure and container bases.
- **AlmaLinux / Rocky Linux:** Binary-compatible RHEL alternatives for enterprise clusters.
- **openSUSE Leap:** Conservative enterprise-ready distribution with YaST management.

### Everyday & Legacy Hardware
- **Linux Mint:** Familiar user experience, ideal for transitioning from Windows.
- **antiX / MX Linux:** Extremely low resource consumption for vintage hardware.
- **Lubuntu / Xubuntu:** Lightweight LXQt and Xfce desktops for resource-constrained laptops.
