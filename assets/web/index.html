Guía Windows 10/11: Solución para GCC (as.exe)

🛡️ ¿Por qué ocurre este problema?

Windows Defender en Windows 10/11 puede clasificar erróneamente el archivo as.exe (GNU Assembler de GCC) como un falso positivo (comúnmente Trojan:Win32/Wacatac.B!ml) y bloquear su extracción, causando el error gcc: fatal error: cannot execute 'as'.

Paso 1: Mantener activa la protección

No añadas exclusiones amplias. Comprueba que la descarga proviene del release oficial y valida el SHA-256 antes de solicitar una revisión por falso positivo.

Paso 2: Revisar el bloqueo

Abre Seguridad de Windows > Protección contra virus y amenazas > Historial de protección. Solo restaura el archivo después de validar el hash y el origen oficial.

Paso 3: Recuperar archivo en Seguridad de Windows

Si Defender ya eliminó as.exe: abre Seguridad de Windows > Protección contra virus y amenazas > Historial de protección, haz clic en la amenaza detectada y selecciona Restaurar.
